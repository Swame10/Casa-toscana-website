# Casa Toscana — ITEC 3020 Assignment 1

## Project
A fictional Italian restaurant website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `script.js` — menu filtering, favourites, form validation and mobile navigation

## JavaScript interactions
1. **Menu search and category filters:** visitors can search dishes and filter by Pasta, Mains or Dessert. The cards update without a page reload.
2. **Favourites:** visitors can add/remove dishes from a favourites Set and see the live count.
3. **Contact form validation:** checks the name, email format and message length, then displays feedback.
4. **Mobile navigation:** opens and closes the navigation menu on smaller screens.

## Run the project
Open `index.html` in a browser. For a smoother development experience, open the folder in Visual Studio Code and use the Live Server extension if installed.

## Notes
- The menu, prices, address and restaurant identity are fictional sample content. Replace them with your group's final content.
- Food photographs are loaded from Unsplash URLs, so an internet connection is needed to display them.
- Google Fonts are loaded online. The page uses fallback fonts if they are unavailable.
- The contact form is a front-end demonstration only. It does not send or store messages.
- No JavaScript frameworks or third-party libraries are used.
